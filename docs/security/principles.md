# Security principles

1. Fail closed for sensitive execution.
2. Least privilege by default.
3. Human identity and non-human identity remain separate trust domains.
4. Secrets never appear in frontend code, logs, API responses, or plaintext persistence.
5. Every executable action eventually carries an organization, actor, correlation ID, policy decision, and result.
6. AI supplies context; deterministic policy retains final authority.
7. Cross-tenant access is treated as a critical security failure.

# AgentGate

**An SOT Product**

AgentGate is the control layer for supervising AI workers inside small and growing organizations.

This repository is security-first, version-aware, mobile-capable, and intentionally evolved foundation by foundation.

## Current checkpoint

- Foundation 0 — Repository & engineering standards
- Foundation 1 — Application bootstrap
- Foundation 2 — Identity & organizations: next

The deployed application currently runs on AppDeploy while the repository preserves portable application and domain boundaries.

## Architecture principles

1. Stable canonical domain; replaceable adapters.
2. Public API versions coexist instead of overwriting each other.
3. Security is architecture, not a pre-launch phase.
4. Dangerous actions must be attributable and explainable.
5. AppDeploy is the deployment environment, not the domain boundary.
